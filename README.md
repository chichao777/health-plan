# 12周健身与健康管理计划

网址：https://chichao777.github.io/health-plan-12weeks/

## 手机与电脑同步

1. 在页面顶部填写邮箱，点击“发送登录邮件”。
2. 输入邮件中的验证码，点击“验证并登录”。如果邮件只有链接，展开“邮件里只有登录链接？”，复制邮件中的完整登录链接粘贴进去验证即可。
3. 在另一设备使用同一邮箱登录。修改先存本机，随后自动同步；保持页面打开时，每15秒检查其他设备的更新，返回页面和重新联网也会触发同步。

首次登录会带入当前浏览器已有的记录；如果云端也有不同记录，同一项的冲突需要选择保留本机还是云端。不同项的修改会自动合并。同步中出现错误时，本机记录会保留，可点击“立即同步”重试。

每个账号有独立的本机缓存和云端记录。切换账号不会把前一账号的记录上传到新账号。退出不会删除云端记录；“清空本机记录”在已登录时会退出并清空该账号在此设备的缓存，下次登录会重新下载云端记录。

## 数据与隐私

网页正文中的基线体检数据已经按本人要求公开。后续输入的个人记录只保存在本机及登录账号对应的 Supabase 数据行中，数据库使用行级权限限制读取和写入。本仓库只有可公开的客户端连接配置，不包含管理员密钥、登录凭证或个人记录备份。

清理浏览器数据、换设备、导入备份前，建议导出 JSON。导入会替换本机记录，已登录时会按同步规则上传相应修改；遇到冲突需选择。CSV 用于查看，JSON 用于恢复。

## 维护

- `index.html`：健康计划、记录表和周次打卡。
- `cloud-sync.js`：邮箱登录、账号缓存、自动同步、冲突提示。
- `sync-core.js`：逐字段合并规则。
- `assets/supabase.min.js`：Supabase JavaScript 客户端。
- `supabase-setup.sql`：独立健康记录表、账号隔离规则及带版本检查的保存函数；仅在首次初始化时执行，不要重复执行。

使用现有 Supabase 项目，旅行记录表独立保留。同步需要该项目保持运行。邮箱验证码使用项目现有邮件设置；如果邮件只有链接，可使用页面提供的粘贴验证功能，无需修改旅行项目的重定向设置。此功能仅接受该 Supabase 项目的邮箱登录链接，验证后立即清空输入框，链接不会保存到健康记录中。如需直接点击邮件链接进入健身页面，需在 Auth URL Configuration 中允许上述健身计划网址。
